# 経路表示

MapViewの店舗マーカーを選択し、徒歩・車を選んで「経路を表示」を押すと、現在地と店舗座標をValhallaへPOSTします。経路の距離・時間はAPIの推定値です。店舗データがサンプルの場合、経路もそのサンプル座標が目的地です。

既定の接続先はFOSSGISの公開デモAPIです。自動連続検索は行わず、同時リクエストは中断します。一般公開前に提供者へのアプリ利用連絡とfair-use条件の確認、または運用用のValhallaサーバーへの変更が必要です。
https://valhalla.github.io/valhalla/

運用サーバーは `VITE_ROUTING_API_URL` に `/route` を含むURLを設定します（CORSと `X-Client-Id` ヘッダーの許可が必要）。秘密キーをURLに含めないでください。

現在地の追跡、再ルート、音声案内は行いません。Overpass・部屋検索・空室判定には依存しません。
