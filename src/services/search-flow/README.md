# 発表用の検索・店舗詳細・予約フロー

- ホームの検索条件画面で「名古屋駅（デモ）」を選ぶと位置情報の許可なしで検索可能。
- DAM＋1〜2名なら701号室、JOYSOUND＋5〜8名なら702号室。空室はOFF、その他は未指定で確認する。
- 保存済み店舗は距離で除外せず、検索結果を5km以内・5km超に分類する。各区分は直線距離順。
- 条件未指定なら部屋未登録店舗も表示する。設備条件がある場合、未登録・未確認の部屋は一致扱いしない。
- 一覧の「地図で選択・経路を表示」から徒歩・車の経路を表示可能。デモでは名古屋駅を経路の起点にも使用する。
- 一覧・地図から詳細へ移動できる。名駅東口店の詳細では登録済み701・702号室を表示する。
- 部屋を選んで予約画面へ進む。店舗・部屋・条件・起点はURLに保持し、戻る操作でも復元する。
- 予約は既存の確認デモ。実送信・空室確保は行わない。空室テストデータの追加は今回の対象外。
- 実際の現在地へ切り替えると通常のGeolocation APIを使用する。デモ起点はURLとタブ内のsessionStorageで保持する。
- 現在地マップ画面の半径選択、Overpass取得、経路APIの実装は維持する。
