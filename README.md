# KaraMAP（カラマップ）

**「今から行ける、自分に合ったカラオケ店」を探すためのWebアプリです。**

現在地や店舗名をもとにカラオケ店を探せます。部屋情報が登録されている店舗では、希望する機種・利用人数で絞り込みや比較ができます。今すぐカラオケを利用したい学生・若者を想定し、外出先でもスマートフォンで使いやすいサービスを目指してグループ制作しています。

## 制作背景

「今からカラオケに行きたい」と思ったとき、近くにあるという理由だけでは、利用する店舗を決められないことがあります。使いたい機種があるか、一緒に行く人数に合う部屋があるか、店舗までどれくらい離れているかも、選ぶために必要な情報です。

KaraMAPでは、こうした情報を別々に調べる手間を減らし、自分たちに合った店舗や部屋を見つけやすくしたいと考えました。

制作にあたって、次のような困りごとを想定しました。

- 近くのカラオケ店と、希望する機種・人数に合う部屋をまとめて探したい。
- 複数の店舗の距離や部屋の違いを比較し、行き先を決めたい。
- 外出先でも、スマートフォンで必要な情報を手軽に確認したい。

## 課題に対して取り組んだこと

| 想定した困りごと | KaraMAPでできること |
| --- | --- |
| 希望に合う店舗を探すのに手間がかかる | 店舗名で検索でき、部屋情報が登録されている店舗はDAMやJOYSOUNDなどの機種・利用人数でも絞り込めます。 |
| 店舗ごとの違いを比較しにくい | 距離や登録済みの部屋情報をまとめて確認し、希望に合う店舗を比較できます。 |
| 近くに条件に合う店舗が見つからない | 5kmより遠い店舗も含めて、近い順に候補を探せます。 |
| 店舗の場所や行き方を調べたい | 地図と徒歩・車の経路で、店舗までの行き方を確認できます。 |
| どの部屋が希望に合うのか分かりにくい | 登録済みの部屋について、機種・定員と検索条件に一致しているかを確認できます。 |
| 外出先で情報を確認しづらい | スマートフォン向けに店舗と部屋の情報を整理し、読みやすさと操作しやすさを目指しました。 |

これらの機能を通して、店舗を探すための手間を減らし、希望に合った行き先を選びやすくすることを目指しています。

## 主な機能

- **店舗検索** — 現在地や店舗名からカラオケ店を探せます。店舗名の一部でも検索できます。
- **部屋の条件検索** — 希望する機種や利用人数に合う、登録済みの部屋を探せます。
- **距離の比較** — 5km以内・5kmより遠い店舗を、近い順に確認できます。表示する距離は直線距離です。
- **地図・経路の確認** — 店舗の場所と、徒歩・車での行き方を確認できます。
- **当日予約のデモ** — 部屋と開始時刻・利用時間・人数を選び、予約内容の確認や取り消しを体験できます。
- **名古屋駅デモモード** — 位置情報の許可なしで、名古屋駅を起点とした店舗探しを体験できます。

## 現在の対応状況

現在は、保存済みの実店舗情報を使った検索や比較、経路の確認、当日予約のデモに対応しています。部屋情報は、ジャンカラ名駅東口店の701号室・702号室を登録しています。

**予約は発表・学習用のデモです。実際の店舗への予約・空室確保・キャンセル連絡は行われません。** 予約の保存と管理は、利用している同じブラウザ内で有効です。

リアルタイムの空室情報には対応していません。料金・営業時間・設備などには未確認の項目があり、ホームの人気店舗やおすすめ表示などにはサンプル情報が含まれます。

## ビジネスプラン（構想）

全国のカラオケ店を探せるサービスへの展開を目指します。利用者や店舗へのヒアリングを通して、需要や運営方法を具体化していく構想です。

### 全国展開と店舗の掲載方針

全国の店舗情報を掲載し、協力店舗を増やすことで、空室情報を確認できる店舗も広げていきます。

| 店舗の協力状況 | 掲載する内容 |
| --- | --- |
| 協力店舗 | 店舗情報に加え、店舗から提供される空室情報を確認できるようにします。 |
| 協力していない店舗 | 確認できた店舗名・所在地などの店舗情報のみを掲載します。 |

空室情報を確認できる店舗には、そのことが分かる表示を付けます。情報提供がない場合や更新状況を確認できない場合は「空室情報未提供」「空室状況未確認」などと表示し、情報の有無が伝わるようにします。

### 想定する利用者と利用場面

主な対象は、放課後や友人との外出中に「今からカラオケに行きたい」と考える学生・若者です。使いたい機種や人数が決まっているグループ、一人で歌える部屋を探している人などが、その日の希望に合う店舗を見つけられるサービスを目指します。

### 利用者と店舗に届けたい価値

| 対象 | 提供したい価値 |
| --- | --- |
| 利用者 | 全国の店舗を距離などで比較し、部屋情報が登録されている店舗では機種・人数でも絞り込むことで、店舗探しにかかる時間を減らすこと。協力店舗では当日の空室を確認でき、将来的には予約まで行えること。 |
| カラオケ店舗 | 当日利用したい人に部屋の特徴を知ってもらい、来店につなげること。将来的には、空いている時間帯や部屋の利用を促すこと。 |

「今から利用したい」という場面に合わせ、店舗の近さと、登録済みの部屋の条件を一緒に比較できる点を、サービスの特徴として育てていきます。

### 収益化の案

利用者の基本的な検索機能は無料で提供し、店舗への集客に応じた収益化を検討します。

| 収益源の案 | 内容 | 実現に向けて確認すること |
| --- | --- | --- |
| 予約の成果報酬 | 予約連携に協力する店舗を対象に、KaraMAP経由の予約で実際に来店した場合に手数料を受け取る方式 | 店舗との提携、来店実績の確認、取消時の扱い、店舗が負担できる手数料 |
| 店舗向け月額プラン | 部屋の魅力を伝える情報掲載や、掲載後の反応を確認できる機能を提供する方式 | 店舗が必要とする機能、情報更新の負担、継続利用したい価格 |
| 広告・特集掲載 | 店舗のキャンペーンなどを広告枠や特集で紹介する方式 | 広告であることが分かる表示、検索の使いやすさ、掲載を希望する店舗の需要 |

料金や手数料率は、店舗へのヒアリングと運営費の試算をもとに検討します。地図・経路などのサービス利用料、店舗情報の確認・更新、問い合わせ対応、集客にかかる費用を見積もり、継続して運営できる収支を目指します。

### サービスを広げる進め方

1. **利用者の課題を確かめる**
   学生などに試してもらい、普段の店舗探しで困っていることや、希望する機種・人数で探せることへの需要を確認します。
2. **全国の店舗情報を充実させる**
   全国を対象に、確認できた店舗情報を掲載していきます。協力していない店舗も掲載し、幅広い地域で店舗を探せるようにします。
3. **当日利用につながるかを検証する**
   予約連携に協力する店舗と実際の予約受付を連携させ、予約から来店につながった件数や、店舗側の運用負担を確認します。
4. **全国で協力店舗を増やす**
   チェーン店や地域の店舗に協力を呼びかけ、空室情報を確認できる店舗を全国に広げます。学生への案内やSNS、協力店舗での紹介による集客を検討します。

### 事業として確かめたいこと

店舗を決めるまでの時間、検索から予約・来店につながる割合、利用者の再利用率、協力店舗の継続率を確認します。店舗への送客で得られる収益と、集客・情報更新・運営にかかる費用も比較し、利用者と店舗の双方に価値があるかを検証します。

## 今後の課題

全国の店舗情報を充実させ、協力店舗から提供される空室状況や料金を継続して更新できるようにすることが今後の課題です。予約受付に協力する店舗とは、実際の予約につなげる仕組みも検討します。また、利用者に実際に使ってもらい、店舗選びの手間を減らせるか、スマートフォンで使いやすいかを確かめながら改善していきたいと考えています。
